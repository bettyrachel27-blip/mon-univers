# Mon Univers — base définitive

Cette version utilise uniquement les fichiers suivants à la racine du dépôt :

- index.html
- style.css
- app.js
- service-worker.js
- manifest.webmanifest
- icons/

## Mise en ligne

1. Dans GitHub, ajoute tous les fichiers de ce ZIP à la racine du dépôt `mon-univers`.
2. Lorsque GitHub demande si les fichiers existants doivent être remplacés, valide le remplacement.
3. Dans Render : `Manual Deploy` → `Clear build cache & deploy`.
4. Ouvre ensuite : `https://mon-univers.onrender.com/?v=7`.

Les données saisies sont enregistrées localement sur l'appareil.
